Quick start

  1. Open the AgentProof analyzer.
  2. Paste a JSON array or JSONL execution trace, or select Import file.
  3. Select Analyze execution to run the six checks in your browser.
  4. Review each finding and export the report as JSON or CSV.
No account, API key, server upload, or external AI service is required. Analysis executes in the browser tab.

Input formats

AgentProof accepts JSON arrays and newline-delimited JSON (JSONL / NDJSON). Each event should be a JSON object. The recommended input limit is 5 MB.

[
  {"type":"tool_call","tool":"search","input":{"query":"docs"}},
  {"type":"tool_result","tool":"search","status":"success","output":"Found 3 documents"}
]

Common recognized fields include type, event, tool, tool_name, input, arguments, output, content, message, status and state. Normalize provider-specific logs to these common fields before analysis.

Analysis workflow

Load a sample

Choose Load demo trace to populate the analyzer with a sample containing known indicators.

Import a trace

Use the file picker for .json, .jsonl, .ndjson or .txt files, or paste the trace directly into the editor. Use Clear before analyzing a different run.

Review findings

Each finding includes its rule identifier, severity, event number, a short explanation and an evidence excerpt. Treat each item as an investigation lead, not a verdict.

Reports & exports

After analysis, the report summarizes total findings by severity. Use Export JSON for structured downstream processing or Export CSV for spreadsheet review. Exported reports may include contextual evidence, so store and share them according to your data-handling policy.

Privacy, scope & limitations

Parsing and analysis occur in the current browser tab. AgentProof does not send trace data to a server, use analytics, or call an external AI endpoint. The original trace remains in the text area until cleared or the tab is closed.

The rules are deterministic heuristics, not a complete SAST, DLP, red-team, or agent-evaluation framework. False positives and false negatives are possible. A clean report is not proof that an execution is safe; human review and application-specific testing remain necessary.

Provider-specific adapters are not included in the free browser edition. This tool is not a safety certification or guarantee.
