Quick start

  1. Open the free scanner.
  2. Select source files from the project. The current browser release accepts up to 500 files, 20 MB total and 2 MB per file.
  3. Choose Run free scan. Files are read and analyzed in the browser tab.
  4. The free result displays only total findings and counts by severity.
  5. Unlock Professional Diagnosis to view technical details, export the report and issue an inspection certificate.
Source file contents are not uploaded for scanning. The scan is static and heuristic; it does not build or execute the project.

Scan coverage

The current first-pass scanner includes pattern checks for:

  • Credential-like strings, common tokens and private-key markers.
  • Bearer authorization values.
  • Dynamic execution patterns such as eval and new Function.
  • Potential unsafe HTML assignment through innerHTML.
  • Potential shell command execution calls.
  • TLS certificate verification disabled by configuration.
  • Potential SQL string concatenation.
  • Debug logging calls.

Supported file extensions include common JavaScript, TypeScript, Python, PHP, Ruby, Go, Java, C-family, Rust, Swift, Vue, Svelte, HTML, CSS, JSON, YAML, shell and SQL files.

Free result

The free tier intentionally reveals only four numbers: total findings, high severity, medium severity and low severity. It does not display file paths, line numbers, rule IDs, evidence snippets or explanations.

Professional Diagnosis — $29

After a Gumroad license is verified, AgentProof reveals each finding's title, severity, file and line location, evidence and suggested remediation guidance. Credential-like evidence is redacted. Findings remain in the browser unless the customer explicitly requests email delivery. AgentProof never edits, patches, repairs or overwrites source code.

Recommendations are intended for the developer who created or maintains the code. The customer should share the report with that developer and request review, correction and appropriate tests.

Inspection certificate and report

The certificate records a unique report ID, issue date, number of files scanned, configured rule count and finding totals by severity. It can be printed or saved as PDF from the browser. JSON and CSV reports are also available for technical review and handoff.

The certificate confirms that the selected files were scanned by the configured AgentProof heuristic checks. It is not a guarantee of security, compliance certification, penetration-test result or proof that the project is free of vulnerabilities.

Email delivery on request

The customer enters their email address and presses Send report to my email. Only then are the diagnostic findings and recommendations sent to the AgentProof email service. The service emails JSON and CSV report attachments to the requested address. Source files are not sent.

Transactional email requires a configured Resend API key and a verified sender address in the API runtime: RESEND_API_KEY and REPORT_FROM_EMAIL. Until those values are configured, customers can download the JSON/CSV report or save the certificate as PDF.

Privacy, limitations and safe use

File reading and pattern matching occur locally in the browser. No source file, scan result or API key is sent to the license-verification API. The license key is sent to the AgentProof API and forwarded to Gumroad for verification; it is not persisted. If the customer explicitly requests email delivery, the report findings (not source files) are sent to the configured email provider to fulfill that request.

This is a limited heuristic scanner, not a full SAST, dependency auditor, runtime test suite, penetration test, compliance certification or guarantee. It can miss vulnerabilities and produce false positives. A zero-finding result means only that these configured patterns did not match the selected files.
